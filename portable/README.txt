Radio EQ - Windows portable version

This folder is meant to be very simple for end users.

Use this flow:
1) Put radioeq.exe in this folder.
2) If needed, run install_tools.cmd to get yt-dlp and FFmpeg.
3) Double-click start.bat

Important:
- Keep radioeq.exe, yt-dlp.exe, ffmpeg.exe and start.bat in the same folder.
- Do not move the files to different folders.
- This is the easiest way to run it without technical steps.

If you already have the final exe, do not run build scripts.
Just open start.bat.
